# T-Rex 2000 — Rain Interactive
Mascota virtual experimental. [Abrir aplicación](https://rain-interactive.github.io/t-rex-2000/).

## Instalación
- **Windows**: Chrome o Edge → menú → Instalar aplicación.
- **Linux**: Chromium/Chrome → menú → Instalar aplicación. En XFCE, usar menú de ventana → Siempre encima para fijar el modo MINI. Firefox ESR no tiene instalación PWA integrada.
- **Android**: Chrome → menú → Instalar aplicación / Añadir a pantalla de inicio.
- **iOS/iPadOS**: Safari → Compartir → Añadir a pantalla de inicio.

La PWA se puede utilizar sin conexión tras una visita en un navegador compatible. Sus estadísticas se guardan solo en ese dispositivo.

No se suministran .exe, .apk ni .ipa nativos; esta es la aplicación web instalable.
